ساخت جدول از بانک خصوصی Google Sheets

رابط و موتور تولید در GitHub Pages اجرا می‌شوند. پرسش‌ها و واژه‌ها فقط پس از ورود مجاز مستقیماً از Google Sheets خوانده می‌شوند؛ هیچ بانک خصوصی روی GitHub قرار نمی‌گیرد.

مشاهدهٔ شیت بانک مرکزی

برای اتصال، یک OAuth Client از نوع Web application با Authorized JavaScript origin برابر https://nimania.github.io و دسترسی Google Sheets API لازم است. Client ID محرمانه نیست؛ رمز و کلید خصوصی وارد نکن.

منتظر ورود با گوگل. بانک خصوصی عمومی نشده است.

انتقال ایمن بانک قدیمی مرورگر

ابتدا در کارگاه اصلی «پشتیبان کامل این مرورگر» را بگیر. فایل پشتیبان JSON نسخهٔ ۲ را اینجا انتخاب کن. انتقال فقط پس از بررسی SHA-256 و تأیید صریح انجام می‌شود؛ داده‌های موجود شیت بازنویسی یا پاک نمی‌شوند و ترکیب‌های سؤال‌وجواب تکراری کنار گذاشته می‌شوند.

هیچ اطلاعاتی انتقال داده نشده است.

تولید خودکار جدول «شرح در متن»

ابتدا بانک گوگل‌شیت را دریافت کن. تنها رکوردهای دارای سؤال و پاسخ وارد موتور می‌شوند؛ جدول ناقص قابل انتشار نیست.

بانک روی Google Sheets خصوصی می‌ماند؛ انتشار جدول‌ها همچنان به بازبینی ویراستاری نیاز دارد.
