# برداشت کامل آبادیس برای بانک مرکزی جدول فارسی

## هدف و وضعیت

این پروژه قرار است **همهٔ صفحات فهرستِ هر ۳۲ حرف** در `https://abadis.ir/crossword/` را پوشش دهد. نمونه‌های قدیمیِ پنج یا شش سرنخ از هر صفحه به‌هیچ‌وجه «صفحهٔ کامل» محسوب نمی‌شوند.

بانک نهایی و صف بررسی در Google Sheets خصوصی هستند:
https://docs.google.com/spreadsheets/d/1Cdai0EBDCNxbS9-UCbCWLGg7fNkk74joq7pbDr_fIEQ/edit

- بانک سؤال‌وجواب خصوصی یا خروجی کامل آن را در مخزن عمومی یا GitHub Pages قرار ندهید.
- استفاده از متن آبادیس همراه با ذکر منبع باشد. به robots.txt، خطاهای دسترسی و سرعت محدود احترام گذاشته شود.
- جابه‌جا کردن ترتیب کلماتِ سؤال ممنوع است؛ اصلاح تایپی باید مجزا و با حفظ متن خام انجام شود.
- همهٔ ورودی‌های استخراج‌شده `reviewed=false` دارند؛ هیچ‌کدام خودکار برای انتشار تأیید نمی‌شوند.

## راه اجرای یک دسته

Workflow: `.github/workflows/abadis-full-scan.yml`

برای اجرای بدون دستکاری Workflow می‌توان فایل **فقط-فراداده** `tools/abadis-full-cursor.json` را روی شاخهٔ `abadis-safe-import` با حروف، صفحه، اندیس و سقف درخواست جدید به‌روزرسانی کرد. این تغییر فقط یک اجرای محدود را فعال می‌کند.

پارامترهای نمونه:
```json
{"letter":"ا","page":1,"offset":0,"max_details":70}
```

خروجی GitHub Actions شامل `next_cursor`, `items`, `errors`, `meta` است؛ این Artifact با مهلت محدود نگهداری می‌شود. پس از پایان هر دسته، فایل خروجی را دانلود و با **نسخهٔ روزِ بانک مرکزی** و صف بازبینی مقایسه کنید. برای خطای دسترسی یا دانلود، همان موقعیت باید دوباره بررسی شود؛ نباید از رکورد معیوب بی‌صدا عبور کرد.

## چه زمانی یک حرف «کامل» است؟

1. تمام شماره‌صفحه‌ها از ۱ تا پایان واقعی، و تمام سرنخ‌های هر صفحه پوشش داده شده باشند.
2. پایان فهرست با شواهد قابل اتکا تأیید شده باشد؛ صفحهٔ خالی به تنهایی اثبات پایان نیست.
3. هیچ درخواست ناموفق حل‌نشده یا `unknown_empty_page` باقی نمانده باشد.
4. ترکیب «سؤال نرمال‌شده + پاسخ نرمال‌شده» با بانک اصلی و صف بررسی تطبیق داده شود.
5. موارد مشکوک به جداسازی کلمه یا چندپاسخی بودن در صف بازبینی بمانند.
6. شمارش، پوشش صفحات، خطاها و شناسهٔ اجرای GitHub در تب «مدیریت برداشت آبادیس» ثبت شود.

**وضعیت مشاهده‌شده تا ۴ نوامبر ۲۰۲۶:** فقط صفحهٔ ۲۳ حرف «ا» به طور کامل (۵۰ عنوان) پیمایش شده و ۲۴ پاسخ خالی/نامشخص داده است. پیمایش ترتیبی از صفحهٔ ۱ جداگانه آغاز شده است. کل آبادیس هنوز استخراج نشده است.
