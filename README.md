# جدول | Jadval Studio

**کارگاه داخلی طراحی جدول فارسی**؛ محل گردآوری سؤال‌وجواب‌های دارای مجوز، استخراج از جدول‌های موجود، دسته‌بندی و تولید، بررسی و تصویب طرح‌های تازه.

## وضعیت فعلی
موتور آزمایشی و واردکنندهٔ فایل‌های `CrosswordJsonV3` در مخزن قرار گرفته‌اند. انتقال تمام جدول‌های واقعی از Firebase **هنوز اجرا نشده است**. طراحی و بررسی باید قبل از انتشار تکمیل شود.

## ابزارهای موجود
- `import_puzzles.py`: وارد کردن فایل‌های JSON دارای مجوز و استخراج سؤال‌وجواب‌ها.
- `generate.py`: تولید طرح‌های اولیه از بانک سؤال‌وجواب (خروجی آزمایشی، نه تضمین جدول کامل روزنامه‌ای).
- `sample.json`: مدخل‌های آزمایشی.

## اجرا
```bash
python3 import_puzzles.py ./licensed-puzzles --output imported-entries.json
python3 generate.py --input imported-entries.json --size 15 --count 3
```

## مرز انتشار
هیچ ورودی خام، پاسخنامهٔ آرشیوی یا پیش‌نویسی نباید مستقیم منتشر شود. جدول‌های تأییدشده باید به قالب بستهٔ انتشار `payamejadval/data/published.json` تبدیل شوند. مخزن `nimania/payamejadval` وب‌سایت عمومی مخاطبان است؛ این مخزن کارگاه داخلی باقی می‌ماند.

## مراحل بعد
۱. دریافت مجاز و نسخه‌برداری آرشیو از Firebase (با مجوز/دسترسی لازم)
۲. پالایش و دسته‌بندی بانک و گزارش تعداد واقعی
۳. موتور backtracking و اعتبارسنجی متقاطع
۴. پنل ویرایش و تأیید و دکمهٔ انتشار برای پیام جدول
